## 0. 问题描述与验收口径

**问题**：`HybridScorer._run_plugins` 计算 `added = float(r.score) * float(r.weight)` 后直接 `new_score = max(0.0, min(100.0, s.score + added))`。`PluginScore.score` / `weight` 是无约束裸 float，当 `added` 为 `NaN` 时 `min(100.0, nan)` 因 `nan < 100.0` 恒为 False 而返回 `100.0`——**全批图片并列满分 100**，top-N 退化为按文件名排序，清理模式下删除集合失真，Agent 侧 `score=100` 无任何异常标记。

**修复后验收口径**（逐条可判定）：

1. 插件返回 `NaN` / `inf` / 超范围分数或超范围权重时，该次返回值**不参与计分**（结果逐位等同「该插件不存在」），并记 WARNING。
2. 全批分数**不出现并列 100**（不因插件输入而饱和）。
3. 合规插件（含内置 `example_aesthetics`）的加分结果与修复前**逐位一致**。
4. 单张图上所有插件的累计增量封顶 ±`PLUGIN_MAX_TOTAL_ADDED`。
5. 同一插件在同一批次内**只告警一次**（不按图片数刷屏）。

## 3. 错误处理

| 异常 / 非法输入 | 处理 | 日志 |
|---|---|---|
| `evaluate` 抛异常 | 保留原逻辑：跳过该图，继续 | 原 WARNING（不变） |
| `evaluate` 返回 `None` | 保留原逻辑：跳过 | 无 |
| `score` / `weight` 非数值（`float()` 抛 `TypeError` / `ValueError`） | 跳过该图，不计分 | WARNING（每插件每批一次） |
| `score` / `weight` 为 `NaN` / `±inf` | 跳过该图，不计分 | WARNING（每插件每批一次） |
| `score` 越出 `[0, 100]` 或 `\|weight\| > 1.0`（有限值） | 跳过该图，不计分 | WARNING（每插件每批一次） |
| 单图累计增量超 `±30` | 截断到 `±30` 后再叠加（不报错） | 无（正常路径的防御性封顶） |
| `cleanup()` 抛异常 | 保留原逻辑：仅告警 | 原 WARNING（不变） |

**原则**：插件返回值是不可信输入，任何违规一律「不采信 + 可观测」，绝不因单个坏插件中断整批评分；与 `_assemble` 的 `math.isfinite` 兜底保持同一口径。

## 4. 参数校验总则

| 参数 | 类型 | 必填 | 合法区间 | 非法处理 |
|---|---|---|---|---|
| `PluginScore.score` | float | 是 | 有限值且 `0.0 ≤ score ≤ 100.0` | 跳过计分 + WARNING |
| `PluginScore.weight` | float | 否（默认 `0.0`） | 有限值且 `\|weight\| ≤ 1.0` | 跳过计分 + WARNING |
| 单图累计增量 | float（内部状态） | — | `±30.0` | 截断后叠加 |

- 校验函数 `_plugin_added(score, weight) -> float \| None` 为**纯函数、不抛异常**：不可采信一律返回 `None`。
- 校验只在 `enable_plugins=True` 的插件阶段执行；未启用插件时 `_run_plugins` 根本不被调用，热路径零影响。
- 不新增任何 CLI / MCP / WebUI 参数与配置项；不改 `PluginScore` 数据结构（frozen dataclass 保持原样）。

### T2 实现：插件输入校验与累计封顶

- **改动文件**：`flashgaze/core/hybrid_scorer.py`
- **输入/输出**：输入=插件返回的 `score` / `weight`；输出=可采信的加分增量（`float \| None`）+ 封顶后的最终分
- **具体改法**：
  1. 模块常量区（紧邻 `PER_IMAGE_TIMEOUT_SEC`）新增：`PLUGIN_SCORE_MIN = 0.0`、`PLUGIN_SCORE_MAX = 100.0`、`PLUGIN_WEIGHT_MAX = 1.0`、`PLUGIN_MAX_TOTAL_ADDED = 30.0`，注释说明取值理由与「H-1」出处。
  2. 新增模块级纯函数 `_plugin_added(score: Any, weight: Any) -> float \| None`：`float()` 转换失败 / `not math.isfinite` / 越界 → `None`；否则返回 `score * weight`（区间已保证乘积有限）。
  3. `_run_plugins`：插件循环外新增 `totals: list[float] = [0.0] * len(results)`；插件循环内新增局部 `warned = False`；用 `_plugin_added` 替换原 `try/except (TypeError, ValueError)` 计算块；`None` 分支记 WARNING 一次后 `continue`；合规分支先按 `±PLUGIN_MAX_TOTAL_ADDED` 截断累计值，取 `delta` 叠加，再 `clamp(0, 100)` 并 `round(..., 2)`。
- **验收标准**：`python -m pytest tests/test_plugins.py -q` 全绿（T1 的 7 个红灯全部转绿）。
