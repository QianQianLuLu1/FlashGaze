## 2. 设计

**新模块级常量**（`hybrid_scorer.py`）：

- `_SERIAL_MAX_LEAKED_THREADS = 3`：线程模式被放弃的挂起线程数上限（对齐 `_POOL_REBUILD_LIMIT=2` 的「少量畸形图可容忍」尺度；3 × (全分辨率 BGR + 引擎) ≈ 数百 MB 封顶）。
- `_SERIAL_HUNG_BUDGET_MULTIPLIER = 4`：累计挂起等待预算 = 4 × PER_IMAGE_TIMEOUT_SEC（运行时相乘，默认 480s；两种模式共用——子进程回收内存但不回收时间）。

**新模块级函数**：

- `_serial_subprocess_worker(img_path, enable_comp, enable_noise, enable_color, enable_portrait, downscale, enable_dedup, queue) -> None`：调用 `_evaluate_cv_and_portrait`，`queue.put(("ok", 四元组))`；`BrisqueIntegrityError` → `("brisque", repr)`；其他 Exception → `("error", repr)`。
- `_run_one_in_subprocess(img_path, engine_args, enable_portrait, enable_dedup, timeout_sec) -> tuple[str, Any]`：`multiprocessing.get_context("spawn")`（必须 spawn：主进程可能已有挂起线程，fork 会继承锁状态）；`Process(daemon=True)` + `ctx.Queue()`；`join(timeout_sec)`；仍存活 → `terminate()` → `join(_TERMINATE_JOIN_SEC)` → 存活则 `kill()`，返回 `("timeout", None)`；正常退出 → 取队列：`("ok", v)` / `("brisque", s)` / `("error", s)`；队列为空 → `("crashed", exitcode)`。进程创建异常（OSError/ValueError）向上抛，由调用方回退线程模式。

**`_score_serial` 重构**（签名不变，内部循环增强）：

1. 新增局部状态：`leaked=0`、`hung_sec=0.0`、`escalated=False`、`subprocess_ok=True`。
2. 每图循环前检查：`leaked >= _SERIAL_MAX_LEAKED_THREADS` 或 `hung_sec >= budget`（budget 运行时相乘）→ 剩余全部未处理图（含当前）统一标 `阶段1超时-串行看门狗预算耗尽` 占位、计入 done、触发 progress_callback（对齐池 exhausted 路径 :701-716）、WARNING 后 break。
3. `escalated and subprocess_ok` → 走 `_run_one_in_subprocess`；捕获 OSError/ValueError → 告警一次、`subprocess_ok=False`、本图落入线程模式。
4. 线程模式超时：`leaked += 1`、`hung_sec += PER_IMAGE_TIMEOUT_SEC`、保留 `_reset_cv_engine_cache()`（MED-1，回退模式下仍需要）；首次挂起 → `escalated=True` + WARNING「后续图改由一次性子进程托管」。
5. 子进程超时：仅 `hung_sec += PER_IMAGE_TIMEOUT_SEC`（无线程泄漏），占位同 `阶段1超时(>Ns)` 文案。
6. `("brisque", s)` → `raise BrisqueIntegrityError(s)` 穿透；`("error", s)` → 与线程模式同文案 `评分异常: ...`；`("crashed", code)` → `串行子进程异常退出(exitcode=N)`。

## 4. 错误处理

| 异常/边界 | 处理 | 日志 |
|---|---|---|
| 子进程创建失败（OSError/ValueError） | 一次性告警，自本图起永久回退线程模式 | WARNING |
| 子进程超时 | terminate→join(5s)→kill，标 `阶段1超时(>Ns)` | WARNING |
| 子进程崩溃（exitcode≠0 或队列空） | 标 `串行子进程异常退出(exitcode=N)` | WARNING |
| 子进程内评分异常 | 标 `评分异常: ...`（与线程模式同文案，不刷屏） | 无（与既有线程路径一致） |
| BrisqueIntegrityError | raise 穿透，绝不降级占位 | 上层既有处理 |
| 泄漏数/预算达限 | 剩余图统一占位 + 计数明细，提前结束循环 | WARNING |
